About this fork
---------------

This is a personal fork of OBS Studio (``kelleyparker/obs-studio``). It builds popular plugin
features into OBS and removes settings its owner never changes. It targets **Windows x64 and
macOS Apple Silicon** only. See ``HANDOFF.md`` for the state of the work and what comes next.

.. note::
   The vertical canvas, settings backup and the changes below have been tested on macOS but
   not yet built or tested on Windows.

Added
^^^^^

- **Multistreaming:** stream to several platforms at once, alongside the main stream. Turn it on
  with one click in Settings → Stream, or configure destinations in Tools → Multistreaming.
  Destinations can share the main encoder or get their own, can use each platform's maximum
  quality, and can stream the vertical canvas.
- **Vertical canvas** (Tools → Vertical Canvas, like Aitum Vertical): a second 9:16 video mix
  with its own scenes and sources, a preview dock, recording, replay buffer and hotkeys.
- **Settings backup and restore** (File → Back Up Settings / Restore Settings): profiles, scene
  collections, app and plugin settings in one ``.zip``, with optional automatic backups when OBS
  closes.
- **50 themes and 50 styles** (Settings → Appearance): Yami plus dark and light themes such as
  Nord, Dracula, Tokyo Night and Solarized, and 50 accent colors that work with every theme.
  The files are generated by ``frontend/tools/generate_themes.py``.

Fixed settings
^^^^^^^^^^^^^^

These are no longer settings. OBS always uses:

- **Audio:** 48 kHz stereo, encoded at 320 kbps. Each stream is lowered to its platform's
  maximum where the platform accepts less (for example 160 kbps for YouTube).
- **Language:** English.
- **Output mode:** Advanced. Profiles that used Simple mode are moved to Advanced, keeping their
  encoder, bitrate and recording settings.
- **Network:** IPv4 and IPv6, the default network adapter and no dynamic bitrate. Streams
  reconnect automatically (every 2 seconds, up to 25 times) and never use a stream delay.
- **Colors:** the theme's own preview and audio meter colors.

Removed
^^^^^^^

- The Accessibility settings page, the Language setting, Audio → General (sample rate and
  channels), all audio bitrate settings, the Output Mode choice, and the Network, Stream Delay
  and Automatically Reconnect sections of Settings → Advanced.
- Every streaming service except Twitch, YouTube (RTMPS and HLS), Facebook Live, Twitter,
  OnlyFans and Custom. WHIP and "Show All" are gone, Twitch and Twitter list only their US
  servers, and the service list is no longer updated online.

What is OBS Studio?
-------------------

OBS Studio is software designed for capturing, compositing, encoding,
recording, and streaming video content, efficiently.

It's distributed under the GNU General Public License v2 (or any later

Contributing
------------

- If you would like to help fund or sponsor the project, you can do so
  via `Patreon <https://www.patreon.com/obsproject>`_, `OpenCollective
  <https://opencollective.com/obsproject>`_, or `PayPal
  <https://www.paypal.me/obsproject>`_.  See our `contribute page
  <https://obsproject.com/contribute>`_ for more information.

- If you wish to contribute code to the project, please make sure to
  read the coding and commit guidelines:
  https://github.com/obsproject/obs-studio/blob/master/CONTRIBUTING.md
  
- Code for the project follows the code style guidelines, located
  here: https://github.com/obsproject/obs-studio/blob/master/CODESTYLE.md

- Developer/API documentation can be found here:
  https://obsproject.com/docs

- If you wish to contribute translations, do not submit pull requests.
  Instead, please use Crowdin.  For more information read this page:
  https://obsproject.com/wiki/How-To-Contribute-Translations-For-OBS

- Contributors to OBS Studio and related repositories are expected to
  follow our Code of Conduct, which can be read here:
  https://github.com/obsproject/obs-studio/blob/master/COC.rst

- Other ways to contribute are by helping people out with support on
  our forums or in our community chat.  Please limit support to topics
  you fully understand -- bad advice is worse than no advice.  When it
  comes to something that you don't fully know or understand, please
  defer to the official help or official channels.
